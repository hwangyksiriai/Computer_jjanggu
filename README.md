## 사진을 찾고 확인하기

파일 이름을 몰라도 사진의 색·사물·분위기를 설명해 찾을 수 있습니다. 바탕화면·다운로드·사진·문서 폴더를 별도 사진 목록으로 확인하며, 분석 중에도 준비된 결과부터 보여줍니다.

- 큰 사진 카드, 두 번 클릭하는 큰 보기, 방향키로 이전·다음 사진 이동
- 찜한 사진 모아보기, 기억나는 모습으로 결과 좁히기, 비슷한 사진 찾기
- 사진 카드와 큰 보기에서 삭제 확인 후 Windows 휴지통으로 이동
- 삭제된 사진은 검색 결과·찜·큰 보기에서 함께 제거

사용 순서와 검증 범위는 [사진 갤러리 사용법](사진-갤러리-사용법.md)에 있습니다. 찜은 이 PC에 저장되며, 모습 검색에는 로컬 사진 모델과 분석이 필요합니다.

## 실행

`실행.bat`을 더블클릭하세요. Python 3.11 이상과 tkinter가 필요합니다. 이 PC의 Python 3.14에서 검증했습니다.
실행기는 Python 의존성을 확인합니다. AI 런타임과 모델은 각 PC에서 준비하며, 별도 드라이브에 설치했다면 `.local/runtime.json`이 실제 런타임 폴더를 가리켜야 합니다. 다른 PC의 설정 파일을 그대로 사용하지 말고 현재 PC의 위치를 연결하세요.

```powershell
python -m pip install -r requirements.txt

```

## 사용 순서

1. **내 짱구 꾸미기**에서 기본 / 잠옷 / 탐정 / 훌라 의상을 고릅니다.
2. 별 핀, 하트, 안경, 크기, 별명, 상황별 변신, 항상 위 표시를 설정합니다. 설정은 자동 저장됩니다.
3. **목소리 들어보기**로 한국어 음성을 확인하고 속도와 볼륨을 조절합니다.
4. **바탕화면 정리 → 내 바탕화면 연결**을 선택합니다. 다른 폴더를 선택할 수도 있습니다.
5. 보관 위치를 확인하고 **정리할 파일 미리보기 → 확인한 파일 정리하기**를 누릅니다.
6. 필요하면 **자동 정리**를 켭니다. 앱이 켜져 있는 동안 30초마다 확인합니다.
7. **아이콘 숨기기 → 짱구만 남기기**를 누르면 배경화면과 캐릭터만 남습니다.

짱구를 클릭하면 주머니가 열립니다. 드래그하면 위치가 바뀝니다. 오른쪽 클릭 메뉴에서 꾸미기, 춤추기, 음소거, 아이콘 복원, 종료를 선택합니다.
듀얼/다중 모니터에서는 짱구를 잡고 다른 화면까지 드래그할 수 있습니다. 왼쪽·위쪽 모니터의 음수 좌표도 지원합니다. 우클릭 → **다음 모니터로 이동**으로도 옮길 수 있습니다. 마지막 위치를 기억하고, 모니터를 분리하면 연결된 화면으로 돌아옵니다. 꾸미기에서 자동 산책도 선택할 수 있습니다.
앱 창의 X와 Esc는 창만 숨깁니다. 완전한 종료는 사이드바 또는 짱구 우클릭 메뉴의 **앱 종료**를 사용하세요.

기획 항목별 구현과 검증 범위는 [기획 대비 구현 현황](IMPLEMENTATION-STATUS.md)을 확인하세요.

- **파일 맡기기:** 탐색기에서 짱구로 파일을 드롭한 뒤 이동 목록과 보관 위치를 확인합니다.

- **작업 트레이:** 검색 결과를 체크해 모은 뒤 파일 목록을 복사하거나 다른 앱으로 끌어갑니다.
- **성장과 보상:** 정리·검색 성공·분류 알려주기로 포인트를 모읍니다. 왕관 30점, 축하 효과 60점, 우주 모자 100점. 쉬어도 감점하지 않습니다.
- **우리 방:** 책상은 검색, 서랍은 꾸미기, 장난감 상자는 트레이, 침대는 집중 모드입니다. 버튼으로 Windows 배경화면을 적용하거나 이전 배경으로 복원할 수 있습니다. 클릭 소품은 앱 안의 방 화면에서 작동합니다.
- **생활 설정:** Ctrl+Shift+Space 전역 호출, 시작 메뉴 앱 검색, 휴지통·다운로드 바로 열기, 자동 집중, 선택형 로그인 시작.
- **캐릭터 동작:** 받기·수레 운반·춤·돌려주기 4동작 각 4프레임, 상의 색상, 독립 모자, 선택형 산책.

## 검색과 간단한 명령

- `인보이스 찾아줘` — 이름뿐 아니라 본문과 이미지 속 글자, 청구 문서의 특징도 검색
- `그중 달러로 된 것만` — 이전 검색에 USD 조건 추가
- `계약서`, `제안서`, `영수증` — 문서 유형별 검색
- `지난달 인보이스`, `최근 파일` — **파일 수정일** 기준 필터
- `정리해줘`, `꾸미기`, `춤춰줘`, `조용히 해줘` — 동작 실행

카드에서 본문 미리보기, 원본 열기, 폴더에서 보기를 제공합니다.
검색 대상은 현재 연결 폴더와 현재 보관 폴더입니다. 다른 보관 폴더로 설정을 바꿔도 기존 파일은 자동으로 옮기지 않습니다.

## 현재 검색 범위와 한계

- TXT / MD / CSV / TSV / JSON / LOG, DOCX 본문, 텍스트 PDF, 이미지 OCR를 지원합니다.
- Windows에 설치된 OCR 언어를 사용합니다. PNG / JPG / BMP 등은 실제 인식 결과로 검색합니다.
- 본문 키워드·청구 필드·의미 임베딩·이미지 특징·색상·개인 태그를 조합합니다. 미리보기의 `비슷한 파일`로 유사 자료를 찾을 수 있습니다.
- 암호 PDF와 40MB 초과 파일은 본문 분석에서 제외합니다. 텍스트 PDF는 최대 60페이지, 스캔 PDF는 최대 12페이지를 OCR합니다. 텍스트는 최대 10만 글자, 의미 임베딩은 앞 3만 글자까지 분석합니다.
- OCR는 기기에 설치된 언어와 이미지 품질에 영향을 받습니다. 미분석 파일 수와 파일별 상태를 표시하며, 완전한 검색을 보장하지 않습니다.
- 목소리 설정에서 참고 음성과 대사를 등록하면 Qwen 로컬 음성 합성으로 새 답변을 만들 수 있습니다. 음성 인식으로 답변 내용과 숫자를 검사해 통과한 음성만 재생하고, 같은 문장은 저장한 음성을 다시 사용합니다. 이 검사는 음색 유사성을 보장하지 않으며, 처음 만드는 문장은 PC 성능에 따라 기다림이 생깁니다. 등록한 음성과 모델은 공개 저장소에 포함되지 않습니다.
- 캐릭터 동작은 생성한 16개 프레임을 재생합니다. 모든 동작이 모든 의상에 별도로 제작된 것은 아니며 동작 중에는 기본 의상이 사용됩니다.
- 꾸미기 배경은 미리보기 무대 색상이며, 실제 Windows 배경은 `우리 방`에서 별도로 적용합니다.
- AI는 작은 로컬 모델이므로 오답과 검색 누락이 가능합니다. 알 수 없는 실제 수신일은 파일 생성일로 둔갑시키지 않습니다. 필요하면 분류 화면에서 직접 기록하세요.
- 자동 집중은 전체화면 크기·회의 창 제목을 이용합니다. 실제 회의 참여 여부를 판별하는 기능은 아닙니다.

## 파일 이동과 복원

- 이동은 선택 폴더의 **최상위 일반 파일**만 대상으로 합니다. 하위 폴더는 검색하지만 통째로 이동하지 않습니다.
- 바로가기, 프로그램, 시스템/숨김 파일, 심볼릭 링크·정션·클라우드 재분석 지점, 다운로드 임시 파일은 자동 이동하지 않습니다.
- 저장 후 10초가 지나지 않은 파일은 미룹니다. 열린 파일이 잠겨 있으면 이동 실패로 기록합니다.
- 이름 충돌 시 `(1)`, `(2)`를 붙이고 기존 파일을 덮어쓰지 않습니다.
- Windows의 동일 볼륨 원자적 이동을 사용합니다. **다른 드라이브로의 자동 이동은 실패로 처리하고 원본을 유지합니다.** 보관함은 원본과 같은 드라이브를 선택하세요.
- 이동 기록과 SHA-256을 저장합니다. 복원 위치에 동명 파일이 있거나 보관 후 내용이 바뀌면 자동 복원을 건너뜁니다.
- 되돌리기를 누르면 자동 정리를 끕니다. 복원 직후 다시 이동하는 일을 막습니다.
- 앱을 종료해도 파일은 일반 폴더로 남고 파일 탐색기에서 열 수 있습니다.
- 아이콘 숨김은 Explorer 표시만 바꿉니다. 정상 종료 시 다시 표시합니다. 강제 종료 후 숨김이 남으면 바탕화면 우클릭 → 보기 → 바탕화면 아이콘 표시를 사용하세요.

## 짱구 말풍선

바탕화면의 짱구를 한 번 클릭하면 흰색 만화 말풍선이 나타납니다. 입력 후 Enter 또는 보내기를 누르면 주머니 창을 열지 않고 검색 결과·대화 답변을 볼 수 있습니다. 결과 파일은 이름을 눌러 열고, “보기”로 미리 봅니다. “그중 달러로 된 것만” 같은 후속 검색과 “춤춰줘”, “조용히 해줘”도 가능합니다. Esc, × 또는 짱구 재클릭으로 닫습니다. 캐릭터를 드래그하면 이동만 합니다. 꾸미기·방 같은 별도 화면을 명시적으로 요청하거나 “주머니 크게 열기”를 누르면 해당 앱 화면이 열립니다. 실제 파일 정리는 별도 미리보기에서 확인 후 실행합니다.

말풍선은 캐릭터가 있는 모니터 안에 배치되며 입력 중 자동 산책을 멈춥니다. `python verify_bubble.py`로 숨긴 주머니 창, 검색·후속 질문·파일 열기·춤·닫기·듀얼 모니터 배치를 검증할 수 있습니다.

처음 연결한 폴더는 백그라운드에서 문서별로 분석합니다. 분석된 파일부터 검색할 수 있으며 목록은 페이지별로 표시합니다. 파일 수가 많으면 초기 분석에 시간이 걸립니다. 분석 중에도 정리·복원·파일 맡기기를 사용할 수 있습니다. 분석 결과를 저장하기 전 파일 상태를 다시 확인하고, 이동과 메타데이터 변경은 순서대로 처리합니다. 개발 도구의 생성 폴더(node_modules, venv, build 등)는 색인에서 제외합니다.

## 저장 데이터

설정, 검색 색인과 정리 기록은 프로젝트의 `.local`에 저장합니다. 파일 내용의 일부가 로컬 검색 DB에 포함됩니다.
클라우드 업로드나 API 키는 없습니다. 파일과 인덱스를 외부로 보내지 않습니다. 모델 설치 단계만 인터넷을 사용하며, 추론 워커는 원격 모델 요청을 비활성화합니다. 음성은 녹음 버튼을 눌렀을 때만 메모리에서 처리합니다.
샘플 모드 보관함은 `.local/보관함`이므로 샘플 정리 후에는 이 폴더도 샘플 파일의 실제 보관 위치입니다.
실제 바탕화면 연결 시 기본 보관 위치는 사용자 Documents 폴더의 `짱구 보관함`입니다.

## 우선순위 개선 (2026-09-18)

- 분석 중 정리·복원·드롭 보관: 전체 분석 완료를 기다리지 않습니다. 변경·이동된 파일의 오래된 분석 결과는 버립니다.
- 자동 변경 반영: Windows 파일 생성·수정·이름 변경·삭제 알림을 약 1.5초 묶어서 처리합니다. 자동 정리 꺼짐 상태에도 동작하며 이동은 하지 않습니다. 현재 분석 중인 문서가 있으면 그 문서 처리 뒤 변경 파일을 우선 분석합니다. 앱 완전 종료 시 감지도 종료됩니다.
- **우리 방 → 바탕화면 가구 클릭 켜기/끄기**: 모니터별 방 화면을 표시하고 책상은 말풍선 검색, 침대는 집중, 서랍은 꾸미기, 장난감은 트레이를 엽니다. Windows 배경 파일 자체가 클릭 기능을 갖는 것은 아니며, 앱 실행 중 별도 바탕화면 화면을 사용합니다. 다른 프로그램이 활성화되면 숨깁니다. OS 배경 설정을 바꾸거나 원래 이미지를 지우지 않습니다.
- **AI · 앱 · 설정 → 원본 짱구 음성 연결**: 첨부 영상에서 추출한 음성을 기본 입력으로 제공합니다. 시작/끝 초를 정해 먼저 듣고 인사·춤·정리 완료·발견 반응에 연결합니다. 원본 대사가 그대로 재생됩니다. 임의의 새 문장으로 합성하지 않습니다. 아직 반응에 연결하지 않은 항목과 긴 대화는 기존 Windows 음성을 사용합니다.
- 나빴던 XTTS 합성 시험 음성은 자동 적용하지 않습니다. 원본 음성 연결은 녹음의 음색을 보존하는 대안이며 자유 대화의 짱구 음성 합성 품질 문제를 해결한 것은 아닙니다.
