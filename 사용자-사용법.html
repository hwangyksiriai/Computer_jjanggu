짱구의 작은 주머니 — 처음 사용하는 분께

바탕화면의 짱구에게 기억나는 문서 내용이나 사진 속 모습을 입력해 찾는 Windows용 앱입니다. 파일 이름과 저장 위치가 기억나지 않는 사진도 기본 개인 폴더에서 함께 찾습니다.

사진 찾기, 세 단계

1. 짱구를 클릭하고 사진 좀 보여줘 또는 파란 의자가 있는 사진 찾아줘라고 입력합니다. 사진 검색을 위해 정리할 폴더를 먼저 고를 필요는 없습니다. 2. 자동으로 열리는 큰 사진 모음에서 여러 사진을 비교합니다. 기억이 더 나면 위쪽 입력란에 사람 없는 것, 더 어두워, 실내야라고 쓰고 기억나는 모습으로 더 찾기를 누릅니다. 3. 원하는 사진을 선택한 뒤 원본 열기 또는 저장된 폴더 열기를 누릅니다. 찾을 위치를 늘리려면 다른 위치도 찾기를 사용합니다.

처음 모습 검색을 사용한다면 사진 모음의 분석 관리 ▾ → 사진 찾기 준비를 누르세요. 모델이 없어도 일반적인 사진 목록과 읽을 수 있는 미리보기부터 볼 수 있습니다. 분석이 끝나지 않은 동안의 0장은 “내 PC에 그런 사진이 없다”는 뜻이 아닙니다.

1. 다른 컴퓨터에서 사용하려면

새 간편 실행판은 짱구주머니.exe를 두 번 클릭하면 됩니다. ZIP 압축 해제나 Python·Node.js 설치가 필요 없습니다. Windows용이며 Mac·휴대폰용은 아닙니다.

- Windows PC에서 사용하세요. 현재 검증한 환경은 Windows / Python 3.14입니다. Mac·휴대폰용 앱이 아닙니다. - 소스 코드를 직접 실행하는 경우에만 Python 3.11 이상과 Node.js 22 이상을 준비합니다. - 첫 설치와 AI 모델 다운로드에는 인터넷이 필요합니다. AI 모델은 여러 GB의 여유 공간이 필요하고 PC 성능에 따라 준비와 첫 검색이 오래 걸릴 수 있습니다. 정확한 최소 메모리·저장 공간은 아직 다양한 PC에서 검증하지 않았습니다.

공식 다운로드: https://www.python.org/downloads/windows/ · https://nodejs.org/

2. 처음 설치하기

1. 짱구주머니.exe를 두 번 클릭합니다. 2. 사진은 바로 사진 보여줘라고 입력합니다. 문서 검색·바탕화면 정리는 내 바탕화면 연결로 시작합니다. 3. 문서는 급여명세서 찾아줘처럼 기억나는 내용을 입력합니다. 4. 문서의 미리보기로 크게 보기에서 검색 근거와 원본을 확인합니다. 사진은 큰 사진 모음이 자동으로 열립니다. 5. 사진 속 모습을 찾으려면 분석 관리 ▾ → 사진 찾기 준비를 누릅니다. 사진 검색에 필요한 모델부터 준비하며 대화·음성 모델을 모두 설치할 필요는 없습니다.

다음부터도 짱구주머니.exe를 누르면 됩니다. 짱구 오른쪽 클릭 → 다시 시작으로 안전하게 재실행할 수 있습니다. 다른 PC에서도 필요한 모델을 준비합니다. 문서는 찾을 폴더를 연결하고, 사진은 그 PC의 기본 개인 폴더부터 확인합니다. “다시 시작”은 현재 실행 파일을 다시 여는 기능이며 새 버전 설치를 대신하지는 않습니다.

소스 ZIP을 받은 개발자는 ZIP 전체 압축 해제 후 처음설치.bat → 실행.bat 순서로 실행합니다. ZIP 안에서 BAT만 실행하면 안 됩니다.

3. 문서 검색·정리할 폴더 연결하기

1. 말풍선의 내 바탕화면 연결 또는 짱구 오른쪽 클릭 → 찾을 폴더 연결을 선택합니다. 메인 화면에서 찾을 폴더 바꾸기도 가능합니다. 2. 보관 폴더를 확인합니다. 파일을 옮길 경우 원본과 같은 드라이브를 선택하세요. 3. 파일 이름을 먼저 등록한 뒤 내용을 분석합니다. 내용 분석 대기가 남아 있으면 아직 못 찾은 파일이 있을 수 있습니다. 분석을 마친 파일은 검색 결과에 자동으로 추가됩니다.

문서 검색 범위는 연결한 폴더와 보관 폴더입니다. 사진은 바탕화면·다운로드·사진·문서 폴더, Windows에 연결된 OneDrive의 바탕화면·사진·문서 폴더, 연결한 폴더와 보관함을 함께 확인합니다.

사진 모음의 다른 위치도 찾기로 다른 드라이브나 폴더를 추가할 수 있습니다. 사진 검색 위치를 추가해도 바탕화면 정리 대상 폴더는 바뀌지 않습니다. 사진 찾기는 원본을 옮기거나 삭제하지 않습니다. PC의 모든 드라이브·시스템 폴더를 자동으로 읽는 기능은 아닙니다.

4. 짱구에게 파일 찾기

짱구를 한 번 클릭하면 머리 위에 말풍선이 나옵니다. 입력하고 Enter / 찾기를 누르세요.

- 인보이스 찾아줘 - 급여명세서 찾아줘 - 계약서 찾아줘 - 파란 표지 제안서 찾아줘 — AI 모델 준비 필요 - 그중 달러로 된 것만 — 말풍선의 현재 결과에서 더 좁히기

파일명이 새 문서.pdf여도 읽어낸 내용에서 문서 특징을 찾을 수 있습니다. 일치하는 파일과 관련 후보는 구분해서 확인하세요. 관련 후보가 반드시 원하는 문서라는 뜻은 아닙니다.

5. 결과를 편하게 보기

문서는 미리보기로 크게 보기를 누르세요.

1. 왼쪽 목록에서 파일을 한 번 클릭합니다. 2. 오른쪽에서 미리보기 이미지와 추출된 본문, 파일 위치, 검색 근거를 확인합니다. 3. 두 번 클릭하거나 원본 열기를 누르면 해당 프로그램으로 열립니다. 4. 위쪽 입력란에 거래처·금액·단어를 입력해 결과를 좁힙니다. 여러 단어는 모두 포함해야 합니다. 5. 목록 필터에서 일치하는 파일 / 관련 후보 / PDF만을 선택할 수 있습니다. 초기화는 이 화면의 추가 조건을 해제합니다.

그중 달러로 된 것만처럼 말풍선에 이어서 입력하거나, 큰 결과 창의 결과 안에서 찾기를 사용하세요. ‘전체 결과’는 PC 전체 파일이 아니라 처음 검색으로 찾은 결과입니다. 좁은 창에서는 미리보기가 목록 아래로 이동합니다.

글씨가 작으면 메인 화면의 글씨 크게를 누르세요. 도움말 · 상태 확인 → 검색 연습에서는 연습용 문서로 사용법을 익힐 수 있습니다. 개인 파일은 이동하지 않습니다.

사진은 파일명 목록 대신 큰 썸네일 모음에서 함께 비교합니다. 한 장을 선택하면 찾은 이유·날짜·위치를 볼 수 있습니다. 원본 열기, 전체 미리보기, 저장된 폴더 열기, 이 사진과 비슷한 사진 찾기를 사용할 수 있습니다. 촬영일 정보가 있으면 “찍은 날”, 없으면 “수정” 날짜로 구별합니다.

- 사진 찾아줘 / 사진 좀 보여줘 / 사진 찾아주세요: 모두 사진 목록을 보여 줍니다. - 파란 의자 사진 찾아줘: 의자 영역의 색을 확인합니다. 전반적으로 파란 사진에 의자가 있어는 전체 색과 의자 유무를 확인합니다. - 사람 없는 것 / 더 어두워 / 실내야: 사진 검색 뒤에 이어서 입력합니다. 기존 대상은 유지하면서 해당 조건을 바꿉니다. 조건 한 단계 뒤로로 이전 검색 조건을 다시 볼 수 있습니다. - 기억나는 모습으로 더 찾기는 장면 조건을 바꿉니다. 파일 정보로 좁히기는 이름·폴더·설명에 포함된 단어를 찾는 별도 필터입니다. - 조건 초기화는 사진 모음 안의 파일 정보·정렬·분석 상태 필터를 초기화합니다. 처음부터 다른 대상을 찾으려면 고양이 사진 찾아줘처럼 새 요청을 입력하세요.

사진 모음에서 분석 관리 ▾를 누르면 검색·분석 멈추기, 분석 계속하기, 사진 찾기 준비가 나옵니다. 필터가 접혀 있으면 먼저 필터·분석 관리를 누르세요. 분석을 멈춰도 지금까지 찾은 사진은 볼 수 있고, 이어할 때 변경되지 않은 사진의 완료된 분석을 재사용합니다.

사물 분석이 끝나지 않은 사진, 작거나 가려진 사물은 놓칠 수 있습니다. 사진 결과와 사물 상자는 후보를 고르는 단서이며 정답 판정이 아닙니다. 복잡한 묘사나 모든 사물을 정확히 이해한다고 보장하지 않습니다.

6. 바탕화면 정리하기

1. 바탕화면 정리 → 정리할 파일 미리보기를 누릅니다. 2. 이동할 파일과 보관 위치를 확인합니다. 3. 확인한 파일 정리하기를 누릅니다. 4. 되돌리려면 정리 기록에서 복원합니다. 보관 후 수정되거나 같은 이름이 생긴 파일은 자동 복원이 안 될 수 있습니다.

자동 정리를 켜면 앱 실행 중 주기적으로 파일을 옮깁니다. 처음에는 수동 정리로 확인하세요. 하위 폴더는 검색하지만 정리 이동은 연결 폴더의 최상위 일반 파일을 대상으로 합니다.

아이콘 숨기기는 아이콘 표시만 숨기는 기능입니다. 파일 삭제가 아닙니다. 복원은 앱 메뉴 또는 바탕화면 우클릭 → 보기 → 바탕화면 아이콘 표시를 사용하세요.

7. 꾸미기·모니터·종료

- 내 짱구 꾸미기에서 의상·모자·크기 등을 바꿉니다. - 춤춰줘라고 입력하면 춤 동작이 나옵니다. - 짱구를 드래그하면 위치가 바뀝니다. 다른 모니터로 끌거나 우클릭 → 다음 모니터로 이동을 사용하세요. - 우리 방에서 가구 기능과 바탕화면 가구 클릭 모드를 선택할 수 있습니다. - 창의 X는 창만 숨깁니다. 완전히 끝내려면 짱구 우클릭 → 앱 종료를 누르세요.

8. 목소리 — 현재 가능한 범위

도움말 · 상태 확인 → 목소리 설정에서 준비합니다. 새 문장 합성과 대사 검사를 연결했지만 원작 짱구와 같은 목소리 품질은 보장하지 않습니다.

1. 음성 엔진 준비를 누릅니다. 처음에는 인터넷과 여러 GB의 여유 공간이 필요합니다. 공간이 부족하면 다른 드라이브를 고릅니다. 2. 참고 음성·영상 연결에서 짱구 혼자 또렷하게 말하는 짧은 구간을 고릅니다. 3. 참고 음성 듣기로 확인하고 정확한 대사를 고칩니다. 배경 음악, 다른 인물의 목소리, 틀린 대사는 품질을 떨어뜨립니다. 4. 새 답변 들어보기를 누릅니다. 처음에는 모델을 불러오느라 몇 분이 걸릴 수 있습니다. 말의 내용 검사를 통과한 음성만 재생합니다. 5. 직접 들어보고 괜찮으면 이 목소리로 모든 답변 말하기를 누릅니다.

요청과 다른 대사로 인식된 음성은 재생하지 않습니다. 녹음 속 임의의 대사나 Windows 음성으로 바꿔 읽지 않습니다. 대사 검사는 목소리 유사도 평가가 아니며, 음성 인식이 잘못 판단할 수도 있습니다. 준비되지 않은 경우에는 말풍선으로 답합니다. 이전에 설정한 음성 방식은 목소리 설정에서 바꿀 수 있습니다.

9. 파일과 개인정보

검색·대화·음성 인식은 설치한 로컬 모델로 처리합니다. 앱은 문서나 음성을 분석 서비스로 업로드하지 않습니다. 최초 설치 시 구성 요소와 모델을 인터넷에서 내려받습니다.

간편 실행판의 설정·검색 DB·등록 음성은 %LOCALAPPDATA%/JjangguPocket에 저장됩니다. 소스 실행판은 프로젝트의 .local을 사용합니다. 이 둘은 저장 위치가 다릅니다. 실행 파일만 바꿔도 같은 PC의 간편판 기록은 유지됩니다.

앱 폴더와 실제 파일 보관함은 별개입니다. 앱을 지우기 전에 보관함의 파일 위치와 필요한 정리 기록을 확인하세요.

10. 문제가 생기면

먼저 도움말 · 상태 확인을 여세요. 저장 공간, 모델 준비 상태 등을 보여 줍니다. 진단 기록 저장에는 개인 문서 내용·파일 이름·검색어·음성 원본을 넣지 않습니다.

- Python을 찾을 수 없음: Python 설치 시 PATH 옵션을 확인하고 설치 창을 새로 여세요. - Node.js/npm을 찾을 수 없음: Node.js를 설치한 뒤 AI설치.bat을 다시 실행하세요. - AI 모델 준비 실패: 인터넷·디스크 공간을 확인하세요. 기본 문서 본문 검색과 AI 의미 검색은 서로 다른 기능입니다. - 사진이 0장 나옴: 사진 모음에 표시된 찾는 위치와 “모습 분석 몇 장 / 등록 몇 장”을 함께 확인하세요. 분석 중·중단 상태라면 분석 관리 ▾ → 분석 계속하기, 모델 미준비라면 사진 찾기 준비를 누릅니다. 확인이 끝난 범위에서도 못 찾으면 조건을 줄이거나 다른 위치도 찾기로 범위를 넓힙니다. - 읽지 못한 사진: HEIC·AVIF·RAW 등의 사진도 발견 목록에 등록하지만 현재 PC에서 읽을 수 없는 형식은 따로 안내합니다. 해당 원본을 열 수 있는 사진 앱에서 확인하거나 JPEG·PNG 사본을 만든 뒤 다시 분석하세요. 모든 휴대폰·카메라 형식을 지원하는 것은 아닙니다. - PC에 내려받지 않은 사진: OneDrive 등 클라우드에만 있는 파일은 저장된 폴더에서 먼저 이 PC로 내려받은 뒤 분석 계속하기를 누릅니다. 앱이 클라우드 전체를 자동으로 다운로드하지는 않습니다. - 문서가 없음: 연결 폴더와 내용 분석 상태를 확인합니다. 암호 문서·미지원 형식·큰 파일은 본문을 못 읽을 수 있습니다. - 무관한 파일이 나옴: 관련 후보인지 확인하고 PDF·거래처·금액으로 좁혀 원본을 확인하세요. - 소리가 안 남: 앱 말소리·음량, Windows 출력 장치, 집중 모드와 해당 반응의 음성 등록 여부를 확인하세요. - 마이크가 안 됨: 음성 입력 설정에서 실제 마이크를 선택하고 Windows 마이크 권한을 확인하세요. - 아이콘이 안 보임: 바탕화면 우클릭 → 보기 → 바탕화면 아이콘 표시를 켜세요.

현재 지원: 텍스트 파일, DOCX, PPTX, XLSX, PDF, 일부 이미지 OCR. 암호 PDF와 40MB 초과 파일은 본문 분석에서 제외하며 PDF·텍스트에는 페이지/길이 제한이 있습니다. 모든 문서를 빠짐없이 찾는 것은 보장하지 않습니다. 이 안내의 설치 과정은 다른 PC용으로 구성했으나 여러 종류의 새 PC에서 설치까지 검증된 정식 배포판은 아닙니다.
