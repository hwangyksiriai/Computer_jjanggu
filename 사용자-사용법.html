짱구의 작은 주머니 — 처음 사용하는 분께

바탕화면의 짱구에게 파일을 찾아달라고 말하거나 입력하는 Windows용 앱입니다. 파일명뿐 아니라 지원되는 문서의 내용도 분석합니다.

1. 다른 컴퓨터에서 사용하려면

배포 ZIP 파일을 내려받아 압축을 풀어야 합니다. 사진이나 바로가기만 복사해서는 실행되지 않습니다. 현재는 개발 중인 체험판으로, 설치 파일 하나만 누르면 끝나는 EXE 설치판은 아직 없습니다.

- Windows PC에서 사용하세요. 현재 검증한 환경은 Windows / Python 3.14입니다. Mac·휴대폰용 앱이 아닙니다. - Python 3.11 이상이 필요합니다. Python 공식 사이트에서 Windows용 Python을 설치하고 Add Python to PATH를 선택하세요. tkinter도 포함해야 합니다. - AI 기능까지 사용하려면 Node.js 22 이상을 추가 설치하세요. 이 프로젝트에서 검증한 Node.js는 24입니다. - 첫 설치와 AI 모델 다운로드에는 인터넷이 필요합니다. AI 모델은 여러 GB의 여유 공간이 필요하고 PC 성능에 따라 준비와 첫 검색이 오래 걸릴 수 있습니다. 정확한 최소 메모리·저장 공간은 아직 다양한 PC에서 검증하지 않았습니다.

공식 다운로드: https://www.python.org/downloads/windows/ · https://nodejs.org/

2. 처음 설치하기

1. 받은 ZIP을 마우스 오른쪽 버튼으로 눌러 모두 압축 풀기를 선택합니다. 2. 바탕화면 정리 대상 밖의 쓰기 가능한 폴더에 보관합니다. 예: 문서 폴더 안의 작은주머니앱. ZIP 안에서 바로 실행하지 마세요. 3. 폴더 안의 처음설치.bat을 두 번 클릭합니다. Python 구성 요소를 내려받고 앱 전용 환경을 만듭니다. 4. 설치 성공 안내가 나오면 실행.bat을 두 번 클릭합니다. 5. 처음에는 샘플 문서로 시작합니다. 인보이스 찾아줘를 입력해 확인하세요. 6. AI 의미 검색·자유 대화·음성 입력을 쓰려면 앱을 종료하고 AI설치.bat을 실행합니다. Node.js 구성 요소와 AI 모델을 내려받습니다. 완료 후 실행.bat으로 다시 켭니다.

다음부터는 실행.bat만 누르면 됩니다. 다른 PC에서는 설치를 새로 진행하세요. 만든 사람의 D: 드라이브나 개인 설정은 필요하지 않습니다.

3. 내 파일 연결하기

1. 주머니 크게 열기 → 바탕화면 정리 → 내 바탕화면 연결을 선택합니다. 다른 폴더를 선택할 수도 있습니다. 2. 보관 폴더를 확인합니다. 파일을 옮길 경우 원본과 같은 드라이브를 선택하세요. 3. 분석이 진행되는 동안 이미 읽은 파일부터 검색할 수 있습니다. 등록·본문·AI 분석 개수를 확인하고 나중에 갱신을 누르세요.

검색 범위는 연결한 폴더와 보관 폴더입니다. PC의 모든 드라이브를 자동으로 읽지는 않습니다. 폴더를 연결했다고 바로 파일을 옮기는 것은 아닙니다.

4. 짱구에게 파일 찾기

짱구를 한 번 클릭하면 머리 위에 말풍선이 나옵니다. 입력하고 Enter / 보내기를 누르세요.

- 인보이스 찾아줘 - 급여명세서 찾아줘 - 계약서 찾아줘 - 파란 표지 제안서 찾아줘 — AI 모델 준비 필요 - 그중 달러로 된 것만 — 말풍선의 현재 결과에서 더 좁히기

파일명이 새 문서.pdf여도 읽어낸 내용에서 문서 특징을 찾을 수 있습니다. 일치하는 파일과 관련 후보는 구분해서 확인하세요. 관련 후보가 반드시 원하는 문서라는 뜻은 아닙니다.

5. 결과를 편하게 보기

결과 넓게 보기를 누르세요.

1. 왼쪽 목록에서 파일을 한 번 클릭합니다. 2. 오른쪽에서 미리보기 이미지와 추출된 본문, 파일 위치, 검색 근거를 확인합니다. 3. 두 번 클릭하거나 원본 열기를 누르면 해당 프로그램으로 열립니다. 4. 위쪽 입력란에 거래처·금액·단어를 입력해 결과를 좁힙니다. 여러 단어는 모두 포함해야 합니다. 5. 목록 필터에서 일치하는 파일 / 관련 후보 / PDF만을 선택할 수 있습니다. 초기화는 이 화면의 추가 조건을 해제합니다.

작은 말풍선에서도 PDF·달러·원화·7일 내 수정 버튼과 결과 안에서 찾기를 사용할 수 있습니다. 한 단계 뒤로 / 전체 결과로 조건을 되돌립니다. 여기서 ‘전체 결과’는 PC 전체 파일이 아니라 처음 검색으로 찾은 결과입니다. 최근 7일은 파일 수정일 기준입니다.

6. 바탕화면 정리하기

1. 바탕화면 정리 → 정리할 파일 미리보기를 누릅니다. 2. 이동할 파일과 보관 위치를 확인합니다. 3. 확인한 파일 정리하기를 누릅니다. 4. 되돌리려면 정리 기록에서 복원합니다. 보관 후 수정되거나 같은 이름이 생긴 파일은 자동 복원이 안 될 수 있습니다.

자동 정리를 켜면 앱 실행 중 주기적으로 파일을 옮깁니다. 처음에는 수동 정리로 확인하세요. 하위 폴더는 검색하지만 정리 이동은 연결 폴더의 최상위 일반 파일을 대상으로 합니다.

아이콘 숨기기는 아이콘 표시만 숨기는 기능입니다. 파일 삭제가 아닙니다. 복원은 앱 메뉴 또는 바탕화면 우클릭 → 보기 → 바탕화면 아이콘 표시를 사용하세요.

7. 꾸미기·모니터·종료

- 내 짱구 꾸미기에서 의상·모자·크기 등을 바꿉니다. - 춤춰줘라고 입력하면 춤 동작이 나옵니다. - 짱구를 드래그하면 위치가 바뀝니다. 다른 모니터로 끌거나 우클릭 → 다음 모니터로 이동을 사용하세요. - 우리 방에서 가구 기능과 바탕화면 가구 클릭 모드를 선택할 수 있습니다. - 창의 X는 창만 숨깁니다. 완전히 끝내려면 짱구 우클릭 → 앱 종료를 누르세요.

8. 목소리 — 현재 가능한 범위

자유로운 답변을 원작 짱구 목소리로 읽는 기능은 아직 완성되지 않았습니다. 체험판은 기본적으로 Windows 음성을 사용할 수 있으며 PC에 설치된 한국어 음성이 필요합니다.

AI · 앱 · 설정 → 원본 짱구 음성 연결에서 사용자가 가진 음성/영상의 구간을 선택하고, 먼저 들어본 다음 인사·검색 시작·파일 발견·결과 없음 등의 반응에 연결할 수 있습니다. 이 기능은 녹음 속 대사를 그대로 재생합니다. 새로운 대사를 만드는 기능이 아닙니다.

원본 전용 모드가 설정된 PC에서는 해당 반응의 녹음이 없으면 말풍선으로만 답합니다. 제작자의 개인 음성·영상·설정은 배포 파일에 포함하지 않습니다.

9. 파일과 개인정보

검색·대화·음성 인식은 설치한 로컬 모델로 처리합니다. 앱은 문서나 음성을 분석 서비스로 업로드하지 않습니다. 최초 설치 시 구성 요소와 모델을 인터넷에서 내려받습니다.

개인 설정, 문서 내용이 포함될 수 있는 검색 DB, 정리 기록, 등록 음성은 앱 폴더의 .local에 저장됩니다. 사용하던 앱 폴더를 통째로 다른 사람에게 보내지 마세요. 공유할 때는 별도로 만든 배포 ZIP을 사용하세요.

앱 폴더와 실제 파일 보관함은 별개입니다. 앱을 지우기 전에 보관함의 파일 위치와 필요한 정리 기록을 확인하세요.

10. 문제가 생기면

- Python을 찾을 수 없음: Python 설치 시 PATH 옵션을 확인하고 설치 창을 새로 여세요. - Node.js/npm을 찾을 수 없음: Node.js를 설치한 뒤 AI설치.bat을 다시 실행하세요. - AI 모델 준비 실패: 인터넷·디스크 공간을 확인하세요. 기본 문서 본문 검색과 AI 의미 검색은 서로 다른 기능입니다. - 찾는 파일이 없음: 연결 폴더가 맞는지, 분석이 끝났는지 확인합니다. 암호 문서·미지원 형식·큰 파일은 본문을 못 읽을 수 있습니다. - 무관한 파일이 나옴: 관련 후보인지 확인하고 PDF·거래처·금액으로 좁혀 원본을 확인하세요. - 소리가 안 남: 앱 말소리·음량, Windows 출력 장치, 집중 모드와 해당 반응의 음성 등록 여부를 확인하세요. - 마이크가 안 됨: 음성 입력 설정에서 실제 마이크를 선택하고 Windows 마이크 권한을 확인하세요. - 아이콘이 안 보임: 바탕화면 우클릭 → 보기 → 바탕화면 아이콘 표시를 켜세요.

현재 지원: 텍스트 파일, DOCX, PPTX, XLSX, PDF, 일부 이미지 OCR. 암호 PDF와 40MB 초과 파일은 본문 분석에서 제외하며 PDF·텍스트에는 페이지/길이 제한이 있습니다. 모든 문서를 빠짐없이 찾는 것은 보장하지 않습니다. 이 안내의 설치 과정은 다른 PC용으로 구성했으나 여러 종류의 새 PC에서 설치까지 검증된 정식 배포판은 아닙니다.
