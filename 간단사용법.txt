짱구 주머니 v5 — 한글 입력 표시 수정

한글 입력 중 마지막 글자가 작게 뜨거나 줄에서 벗어나는 현상을 줄이기 위해
조합창의 글꼴·크기를 검색창에 맞추고 조합 위치를 입력 커서와 동기화했습니다.
찾기나 Enter를 누르면 조합 중인 글자를 먼저 확정한 뒤 검색합니다.
Windows 키보드나 한글 입력기 설정을 바꾸지는 않습니다.

검증: 실제 Windows IME 글꼴 읽기 확인, 한글 검색어 보존, 기존 검색·파일 열기·복원.
사용자가 촬영한 입력 현상을 실제 키보드 입력으로 재현해 육안 비교한 것은 아닙니다.

사용: 기존 짱구 오른쪽 클릭 → 완전히 종료 → ZIP 전체 압축 풀기 → 짱구주머니.exe.
짱구 클릭 → 검색어 입력 → 찾기. 파일 이름을 누르면 열립니다.
급여명세서 같은 문서 유형은 파일명 외에도 읽힌 본문과 이미지 글자를 기준으로 찾습니다.
원본 짱구 성우 음성은 포함되어 있지 않습니다.
