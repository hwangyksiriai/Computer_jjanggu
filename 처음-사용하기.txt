짱구 주머니 · 간편 실행판

최신 버전 2026.09.23.6 시작하기
  GitHub 배포 페이지에서 짱구주머니-2026.09.23.6-Windows.zip을 받으세요.
  마우스 오른쪽 → '모두 압축 풀기' → 짱구주머니.exe를 두 번 누르세요.
  Python 설치나 명령어 입력은 필요 없어요. exe와 _internal 폴더는 함께 두세요.
  폴더 안의 '간단 사용설명서.html'에 새 기능과 구현 예정 기능을 설명해 두었어요.

이번에 추가한 기능
  파일 옆 ☆로 고정하고 사진의 ♡로 찜하면, 앱을 껐다 켜도 기억해요.
  '내 모음 → 자동 모음'에서 조건을 정하면 새로 읽은 파일도 함께 모아요.
  '파일 정보 → 다른 파일과 비교 → 바뀐 내용 보기'에서 글자 차이를 확인해요.
  확인한 문서는 '내 최종본으로 표시'로 기억할 수 있어요.
  '내 모음 → 메일 첨부파일'에서 메일을 연결하거나 저장한 .eml을 가져오세요.
  네이버·네이버웍스·Gmail·회사 IMAP을 지원하며 Outlook은 .eml 가져오기를 사용해요.

사진 찾기는 세 단계면 됩니다.
1. 짱구주머니.exe를 더블클릭하고, 짱구에게 '사진 좀 보여줘'라고 입력하세요.
   '파란 의자가 있는 사진 찾아줘'처럼 기억나는 모습을 말해도 됩니다.
   사진 검색은 정리할 폴더를 먼저 연결하지 않아도 시작할 수 있습니다.
2. 큰 사진 모음에서 사진들을 나란히 보세요.
   '사람 없는 것', '더 어두워', '실내야'를 입력하고
   '기억나는 모습으로 더 찾기'를 눌러 이어서 찾으세요.
3. 원하는 사진을 선택하고 '원본 열기' 또는 '저장된 폴더 열기'를 누르세요.

어디에서 사진을 찾나요?
  바탕화면·다운로드·사진·문서 폴더를 함께 확인합니다.
  Windows에 연결된 OneDrive의 바탕화면·사진·문서 폴더와 기존 연결 폴더·보관함도 포함합니다.
  다른 드라이브는 사진 모음의 '다른 위치도 찾기'로 추가하세요.
  사진 검색 위치를 추가해도 정리 대상 폴더는 바뀌지 않습니다.
  사진 찾기로 원본을 옮기거나 삭제하지 않습니다.

처음 사진 모습을 분석할 때
  사진 모음의 '분석 관리 ▾ → 사진 찾기 준비'를 누르세요.
  사진에 필요한 모델부터 내려받으며, 최초 다운로드에는 인터넷과 여유 공간이 필요합니다.
  대화·음성 모델을 모두 준비할 필요는 없습니다.
  모델이 없어도 일반 사진 목록과 읽을 수 있는 미리보기는 볼 수 있습니다.
  준비 후 사진 분석은 PC에서 처리하며 외부 분석 서비스로 보내지 않습니다.

0장이 나오거나 오래 걸릴 때
  0장이 나왔다고 내 PC에 사진이 없다는 뜻은 아닙니다.
  사진 모음 위쪽의 찾는 위치와 등록 수·분석 수를 함께 확인하세요.
  '분석 관리 ▾ → 검색·분석 멈추기'로 중단할 수 있습니다.
  '분석 계속하기'로 이어하며, 지금까지 찾은 사진과 완료된 분석은 유지됩니다.
  메뉴가 안 보이면 '필터·분석 관리'를 눌러 펼치세요.
  확인이 끝나도 못 찾으면 조건을 줄이거나 '다른 위치도 찾기'를 사용하세요.
  HEIC·RAW 등 읽지 못한 사진은 따로 안내합니다. 원본 앱이나 JPEG·PNG 사본으로 확인하세요.
  클라우드에만 있는 파일은 먼저 PC로 내려받은 뒤 분석을 이어하세요.
  모든 카메라 형식·모든 사물·모든 PC에서 정확히 찾는 것은 보장하지 않습니다.

조건을 바꾸고 되돌리기
  '파란 의자'는 의자 영역의 색, '전반적으로 파란 사진에 의자'는 전체 색을 확인합니다.
  '사람 없는 것' 같은 조건은 사진 검색 뒤에 이어서 입력하세요.
  '조건 한 단계 뒤로'는 이전 검색 조건으로 돌아갑니다.
  '파일 정보로 좁히기'는 이름·폴더·설명에 포함된 단어 필터입니다.
  '조건 초기화'는 이 파일 정보·정렬·분석 상태 필터를 초기화합니다.
  다른 대상을 새로 찾을 때는 '고양이 사진 찾아줘'처럼 입력하세요.

급여명세서 같은 문서 찾기
  처음 한 번 '찾을 폴더'에서 내 파일이 있는 위치를 연결하세요.
  '급여명세서 찾아줘'라고 입력하면 직접 연결한 폴더들에서 찾습니다.
  처음에는 파일 이름을 등록하고 본문·스캔 글자를 차례로 확인합니다.
  '내용 분석 대기'가 남으면 아직 못 찾은 문서가 있을 수 있습니다.
  '미리보기로 크게 보기'에서 찾은 근거와 원본을 확인하세요.
  급여명세서를 언급만 한 문서는 '관련 후보'로 표시합니다.

실행 / 다시 시작 / 종료
  간편 실행판은 Python·Node.js를 별도로 설치하지 않고 EXE를 실행합니다.
  짱구를 오른쪽 클릭하면 '다시 시작', '완전히 종료'가 있습니다.
  진행 중인 파일 작업이 있으면 끝날 때까지 기다립니다.
  다시 시작은 현재 EXE를 다시 여는 기능입니다. 새 버전은 새 EXE를 실행해야 합니다.

소리
  '도움말 · 상태 확인' → '목소리 설정'을 여세요.
  엔진 준비 → 참고 음성 연결 → 정확한 대사 확인 → 새 답변 들어보기 순서입니다.
  직접 들어보고 적용하면 새 답변을 합성합니다. 처음 생성에는 몇 분이 걸릴 수 있습니다.
  대사 검사에서 다른 말로 인식되면 재생하지 않고 이유를 표시합니다.
  원작과 같은 목소리를 보장하지 않습니다. 등록 전에는 임의의 Windows 음성으로 대신 읽지 않습니다.

글씨가 작거나 사용법을 모르겠을 때
  메인 화면의 '글씨 크게'를 누르세요. 결과 목록과 말풍선에도 적용됩니다.
  '도움말 · 상태 확인'에서 검색 연습을 해 보세요. 개인 파일은 이동하지 않습니다.
  문제가 있으면 같은 화면에서 상태를 확인하고 진단 기록을 저장할 수 있습니다.

정리
  '정리해줘'를 입력하고 이동할 파일 목록을 먼저 확인하세요.
  정리한 파일은 보관 폴더로 옮겨지며, '방금 정리한 것 되돌리기'로 복원합니다.

간편 실행판의 설정과 검색 기록은 이 PC의 사용자 폴더에 저장됩니다.
실행 파일을 옮기거나 새 버전으로 바꿔도 같은 PC의 기록은 유지됩니다.
기존 소스 실행판의 데이터와는 저장 위치가 다릅니다.
